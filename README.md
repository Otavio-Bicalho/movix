# movix
Ferramenta Web na qual permite que pessoas físicas e pessoas jurídicas verificarem o valor do combustível (gasolina, etanol e afins) conforme sua localização atual.

O Movix tem como objetivo facilitar a busca por estabelecimentos relacionados a manutenção do veículo, permitindo que os usuários encontrem rapidamente locais próximos, com informações úteis como localização, serviços disponíveis e, preços

Os usuários alimentam a plataforma com informações tendo como base a última experiência no estabelecimento
